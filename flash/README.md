# flash

- `flash-from-factory.py` — flashea el slave desde el Linux de fabrica, por
  serie (login supervisor + `mtd write`). Las credenciales van por env
  (`FACTORY_PASS`), no hardcodeadas.
- `flash-in-place.md` — flasheo en caliente desde OpenWrt (sin BootROM).

Ver `../docs/02` y `../docs/06`.
